# data_filter.py — 敏感数据过滤工具

## 概述
该文件提供了在将文本发送到 LLM 之前**过滤敏感信息**的功能。通过正则表达式识别并替换身份证号、手机号、邮箱地址等个人隐私信息，防止敏感数据泄露到外部 LLM 服务。

## 函数详细说明

### filter_sensitive_data(text)
- **功能**: 过滤文本中的敏感信息，用于发送到 LLM 之前
- **参数**: `text: str` — 需要过滤的原始文本
- **返回值**: `str` — 过滤后的文本，敏感信息已替换为占位符
- **关键逻辑**: 按顺序对以下敏感信息进行正则匹配和替换：

#### 过滤规则

| 序号 | 敏感类型 | 正则模式 | 替换为 | 说明 |
|------|----------|----------|--------|------|
| 1 | 身份证号 | `\b\d{17}[\dXx]\b` | `[身份证号已隐藏]` | 18 位，末位可以是数字或 X/x |
| 2 | 手机号 | `\b1[3-9]\d{9}\b` | `[手机号已隐藏]` | 中国大陆 11 位手机号格式 |
| 3 | 邮箱地址 | `\b[\w.-]+@[\w.-]+\.\w+\b` | `[邮箱已隐藏]` | 标准邮箱格式 |

#### 边界情况处理
- 如果输入 `text` 为空字符串或 None-like 值，直接返回原值，不做处理
- 使用 `\b`（单词边界）确保不会误匹配嵌入在长数字串中的模式

#### 使用示例
```python
>>> filter_sensitive_data("我的身份证 110101199001011234 和手机 13800138000")
'我的身份证 [身份证号已隐藏] 和手机 [手机号已隐藏]'

>>> filter_sensitive_data("联系邮箱 test@example.com")
'联系邮箱 [邮箱已隐藏]'

>>> filter_sensitive_data("")
''
```

## 依赖关系
- `re` — Python 正则表达式模块

## 注意事项
- 过滤规则按顺序执行，不会产生冲突
- 替换后的占位符长度可能与原文不同，但不影响 LLM 理解上下文
- 当前仅支持中国大陆身份证号和手机号格式，如需支持其他地区格式需扩展正则
- 使用 `\b` 边界匹配，确保不会错误匹配如 "12345678901234567890"（20 位数字）中的 18 位子串
- 该模块应在**所有**发送到 LLM 的文本上调用，不可遗漏
- 占位符使用中文，LLM 可以理解这些位置原本是敏感信息
