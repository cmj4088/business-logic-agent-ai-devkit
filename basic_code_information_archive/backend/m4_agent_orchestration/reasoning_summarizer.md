# reasoning_summarizer.py — 推理摘要生成器

## 概述
该文件实现了 M4 Agent 编排模块中的推理摘要生成功能。在多 Agent 协作完成后，需要将各 Agent 的推理过程浓缩为简洁的中文摘要，便于前端展示和用户快速理解。

## 函数/类详细说明

### generate_reasoning_summary()
- **功能**: 生成 Agent 推理过程的中文摘要
- **参数**:
  - `agent_outputs` (list[dict]): Agent 输出列表，每个元素格式为 `{"role": "product_manager", "content": "...", ...}`
  - `max_length` (int): 摘要最大长度（字符数），默认 200
- **返回值**: str — 中文摘要字符串
- **关键逻辑**:
  - 如果 agent_outputs 为空，返回 "无推理过程"
  - 遍历每个 Agent 的输出：
    - 使用正则 `[。！？\n]` 分割句子
    - 过滤掉长度不足 10 个字符的短句
    - 取前 2 个有效句子
    - 格式化为 `"{role}：{句子1}。{句子2}"`
  - 用分号（；）连接所有 Agent 的摘要
  - 如果总长度超过 max_length，截断并在末尾添加 "..."
  - 如果结果为空字符串，返回 "推理过程已生成"

## 依赖关系
- `re`: 标准库，用于句子分割

## 注意事项
- 句子分割使用的是中文标点（。！？）和换行符（\n），对英文标点（. ! ?）不适用
- 短句过滤阈值 10 个字符可以过滤掉类似 "好的"、"是的" 等无意义的短回复
- 摘要截断是在字符级别进行的，可能在多字节 UTF-8 字符中间截断，但 Python 3 的字符串切片是 Unicode 安全的
- 该函数在 orchestrator.py 的 `orchestrate()` 方法中被调用，在所有 Agent 执行完毕后生成摘要
- 如果 Agent 输出内容非常短或全是短句，摘要可能为空，此时返回兜底文本 "推理过程已生成"
