# deadlock_detector.py — 死循环检测器

## 概述
该文件实现了 M4 Agent 编排模块中的死循环检测功能。在辩论模式（Debate Mode）中，多个 Agent 多轮对话可能陷入重复输出相同观点的"死循环"。该模块通过计算连续多轮输出的语义相似度来检测这种情况，当检测到连续 N 轮无新观点时触发终止。

## 函数/类详细说明

### calculate_similarity()
- **功能**: 计算两段文本的简单语义相似度
- **参数**:
  - `text1` (str): 第一段文本
  - `text2` (str): 第二段文本
- **返回值**: float — 相似度分数，范围 0.0 ~ 1.0
- **关键逻辑**:
  - 使用基于字符 2-gram 的 Jaccard 相似度算法
  - 对文本进行清理：移除标点符号、转小写
  - 分词策略同时支持中文和英文：提取所有连续 2-gram 字符序列，并加入单字
  - Jaccard 相似度 = 交集大小 / 并集大小
  - 如果任一文本为空，返回 0.0

### DeadlockDetector（类）
死循环检测器，追踪辩论模式中的多轮输出并进行相似度判断。

#### __init__()
- **功能**: 初始化检测器
- **参数**:
  - `threshold` (float): 相似度阈值，默认 0.85。当所有轮次对之间的相似度都超过此值时认为无新观点
  - `max_rounds_no_new_ideas` (int): 连续无新观点的最大轮数，默认 3。达到此轮数后判定为死循环
- **关键逻辑**: 初始化空的 round_texts 列表用于存储每轮文本

#### add_round()
- **功能**: 添加一轮输出，并检测是否出现死循环
- **参数**:
  - `text` (str): 本轮 Agent 输出的文本
- **返回值**: bool — True 表示检测到死循环，应终止辩论；False 表示正常
- **关键逻辑**:
  - 将文本追加到 round_texts 列表
  - 如果轮数不足 max_rounds_no_new_ideas，直接返回 False
  - 取最近 N 轮的文本，两两计算相似度
  - 如果任意一对文本的相似度低于阈值，说明仍有新观点，返回 False
  - 如果所有对的相似度都高于阈值，判定为死循环，返回 True

#### reset()
- **功能**: 重置检测器状态
- **参数**: 无
- **返回值**: None
- **关键逻辑**: 清空 round_texts 列表

## 依赖关系
- `re`: 标准库，用于文本清洗（移除标点符号）

## 注意事项
- 字符 2-gram 是中英文混合场景下的简单有效方案，但并非真正的语义相似度计算，对于同义词替换等场景可能误判
- threshold 默认 0.85 较高，意味着只有文本高度重复时才会触发；可根据实际辩论内容调整
- 检测算法是 O(n^2) 两两比较，但 n 通常很小（默认 3），性能影响可忽略
- 该检测器在 orchestrator.py 的 `_run_debate()` 方法中被使用，每轮辩论结束后调用一次
