# language_detector.py — 语言检测器

## 概述
该文件实现了 M4 Agent 编排模块中的语言检测功能。由于系统的目标用户是中文用户，需要确保 LLM 的输出是中文。当检测到输出非中文时，触发重试机制，要求 LLM 重新生成中文回答。

## 函数/类详细说明

### is_chinese()
- **功能**: 检测文本是否主要为中文
- **参数**:
  - `text` (str): 待检测的文本
- **返回值**: bool — True 表示主要为中文
- **关键逻辑**:
  - 如果文本为空，直接返回 True（不拦截空文本）
  - 使用正则表达式 `[一-鿿]` 匹配中文字符（Unicode 范围：CJK 统一表意文字基本区）
  - 计算中文字符数量与总字符数（去除空白字符后）的比例
  - 如果总字符数为 0（纯空白），返回 True
  - 中文字符占比 >= 30% 即认为主要是中文

### check_language()
- **功能**: 检查语言并返回是否需要重试
- **参数**:
  - `text` (str): 待检测的文本
- **返回值**: tuple[bool, str] — (是否为中文, 需要重试的原因)
- **关键逻辑**:
  - 调用 is_chinese() 进行判断
  - 如果是中文：返回 (True, "")
  - 如果不是中文：返回 (False, "输出非中文，需要重试")

## 依赖关系
- `re`: 标准库，用于正则匹配中文字符

## 注意事项
- 中文字符判断阈值 30% 较为宽松，适用于中英混合的技术文档场景
- 正则范围 `[一-鿿]` 覆盖了 CJK 基本区（U+4E00 到 U+9FFF），但不包括扩展区、标点符号和全角字符
- 该检测器在 orchestrator.py 的 `_invoke_agent()` 方法中被调用，非中文时最多重试 3 次
- 如果 LLM 持续输出非中文，最终会返回失败结果，不会无限重试
