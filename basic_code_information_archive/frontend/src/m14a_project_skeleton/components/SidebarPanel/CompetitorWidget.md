# m14a_project_skeleton/components/SidebarPanel/CompetitorWidget.tsx — 竞品动态小组件（骨架）

## 概述
竞品动态小组件的骨架容器，展示竞品信息。当前显示"暂无数据"和"竞品信息将在后续版本完善"，为静态占位。

## 组件详细说明

### CompetitorWidget({ projectId })
- **功能**: 竞品动态小组件
- **Props**: `projectId` (string) — 项目 ID（当前未使用）
- **关键逻辑**: 静态显示"暂无数据"
- **UI 结构**: 白色卡片，标题"竞品动态"，居中显示占位符

## 依赖关系
- `react`: FC

## 注意事项
- 骨架组件，后续版本需要接入竞品分析数据
