# IPD Excel 处理 Skill

当用户需要创建或处理 Excel 文件时，使用本 Skill。特别适用于 IPD 项目中的各类表格交付物。

## 核心能力

### 读取
- 读取 .xlsx / .xlsm / .csv / .tsv 文件
- 按 Sheet 名称读取指定工作表
- 读取单元格范围、命名区域
- 检测合并单元格、数据验证、条件格式

### 创建与编辑
- 创建新的 .xlsx 文件
- 写入数据到指定 Sheet 和单元格
- 添加/删除 Sheet
- 设置单元格格式（字体、颜色、边框、对齐、数字格式）
- 合并/取消合并单元格
- 设置行高和列宽
- 添加数据验证（下拉列表、数值范围等）
- 添加条件格式（色阶、图标集、数据条）

### 公式与计算
- 插入公式（SUM, AVERAGE, IF, VLOOKUP, XLOOKUP 等）
- 命名区域管理
- 自动填充

### 图表
- 柱状图、折线图、饼图、散点图
- 组合图
- 图表样式和格式化
- 数据标签和标题

### 格式化
- 表格样式（交替行颜色、边框）
- 数字格式（货币、百分比、日期、科学计数）
- 文本换行
- 冻结窗格
- 打印区域设置

## IPD 特定模板

### BOM 成本表
- 物料清单：物料编码、名称、规格、数量、单价、总价
- 自动汇总：物料总成本、人工成本、制造成本
- 公式：`=SUM(单价*数量)`，`=总成本*(1+利润率)`

### 财务预算表
- 收入/支出分类：按阶段/部门/品类
- 自动汇总：预算 vs 实际，偏差分析
- 条件格式：超预算自动标红
- 图表：预算执行趋势图

### 项目进度表
- 甘特图格式：阶段、活动、开始/结束日期、负责人、状态
- 自动计算：工期、完成百分比
- 条件格式：延期/风险自动标记

### 竞品对比矩阵
- 维度：功能、价格、性能、市场份额
- 评分：1-5 分制
- 自动计算：加权总分、排名
- 图表：雷达图对比
