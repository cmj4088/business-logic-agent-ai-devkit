# IPD 数据分析 Skill

当用户需要分析 IPD 项目相关的数据（市场数据、财务数据、质量数据、竞品数据等）时，使用本 Skill。

## 工作流程

### 1. 安全探查
- 仅读取文件元数据和少量样本（前 5 行），防止 Token 溢出
- 推断列类型（数值/类别/日期/文本）

### 2. 质量体检
- 检查缺失值、重复行、异常值
- 检查数据类型一致性
- 输出质量报告摘要

### 3. 数据清洗
- 处理缺失值（填充/删除）
- 去除重复行
- 格式化日期列
- 统一单位

### 4. 分析与计算
- 描述性统计（均值、中位数、标准差、分位数）
- 分组聚合（按品类/时间/地区）
- 趋势分析（环比、同比）
- 相关性分析
- 假设检验（如需）

### 5. 可视化
- 趋势图（折线图）
- 对比图（柱状图）
- 分布图（直方图/箱线图）
- 相关性热力图
- 饼图/环形图（占比）

### 6. 报告生成
- 输出 Markdown 格式分析报告
- 包含：数据概况 → 关键发现 → 详细分析 → 结论建议

## IPD 特定场景

### 市场分析
- 市场规模（TAM/SAM/SOM）估算
- 竞品价格/功能对比矩阵
- 用户需求频次统计
- 市场份额趋势

### 财务分析
- ROI 计算（成本 vs 收益）
- 现金流预测
- 盈亏平衡点分析
- 敏感性分析

### 质量分析
- 缺陷率趋势
- 测试通过率统计
- 回归分析
- 质量指标仪表盘

### 制造分析
- BOM 成本核算
- 供应链风险评估
- 产能利用率

## 示例
- "分析这份市场调研数据，计算 TAM/SAM/SOM"
- "读取竞品对比 Excel，生成价格功能对比矩阵"
- "分析项目质量数据，输出缺陷趋势图和测试通过率"
- "计算 ROI，做敏感性分析，输出财务建议"

## 输出格式
- 分析报告：Markdown
- 图表：PNG（使用 Matplotlib/Seaborn）
- 数据表：CSV 或 Excel（如需导出）
