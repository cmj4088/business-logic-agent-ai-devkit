# IPD Word 文档生成 Skill

当用户需要创建 IPD 项目相关的正式文档（MRD、PRD、技术方案、测试报告等）时，使用本 Skill。

## 核心能力

### 文档结构
- 创建标题层级（H1-H6）
- 自动生成目录（TOC）
- 分节符（封面/正文/附录）
- 页码（不同节不同格式）
- 页眉/页脚（奇偶页不同）
- 脚注和尾注

### 文本与样式
- 字体、字号、颜色、粗体/斜体/下划线
- 段落间距和缩进
- 项目符号和编号列表
- 多级列表（1.1, 1.2 等）
- 样式模板（标题、正文、引用、代码块）

### 表格
- 创建和格式化表格
- 合并/拆分单元格
- 表格样式（交替行颜色、边框）
- 表格内公式计算

### 图像与图表
- 插入图片（设定尺寸、对齐、环绕方式）
- 插入图表（柱状图、折线图、饼图）
- 添加图题和表题（自动编号）

### 高级功能
- 交叉引用（图表编号、章节编号）
- 书签和超链接
- 水印（机密/草稿）
- 文档保护（只读/编辑限制）
- 批注和修订

## IPD 特定模板

### MRD（市场需求文档）
- 封面：项目名称、版本、日期、作者
- 目录
- 1. 执行摘要
- 2. 市场背景与趋势
- 3. 目标用户画像
- 4. 竞品分析
- 5. 市场需求清单
- 6. 产品定位
- 7. 附录

### PRD（产品需求文档）
- 封面：项目名称、版本、日期、作者
- 目录
- 1. 执行摘要
- 2. 产品背景与目标
- 3. 功能需求列表
- 4. 非功能需求
- 5. 用户故事
- 6. 验收标准
- 7. 附录

### 技术方案文档
- 封面：项目名称、版本、日期、作者
- 目录
- 1. 执行摘要
- 2. 系统架构
- 3. 技术选型
- 4. 模块设计
- 5. 接口定义
- 6. 风险评估
- 7. 附录

### 测试报告
- 封面：项目名称、版本、日期、测试人员
- 目录
- 1. 测试概览
- 2. 测试范围
- 3. 测试环境
- 4. 测试结果统计
- 5. 缺陷分析
- 6. 质量评估
- 7. 附录

### 商业论证
- 封面：项目名称、版本、日期、作者
- 目录
- 1. 执行摘要
- 2. 市场机会
- 3. 财务预测
- 4. 风险评估
- 5. 投资回报分析
- 6. 建议
- 7. 附录

## 示例
- "生成 MRD 文档，产品是智能家居中控，目标市场是年轻家庭"
- "创建技术方案文档，系统架构是微服务，技术栈是 Spring Cloud"
- "生成测试报告，测试结果数据从 Excel 导入"
- "创建商业论证文档，包含财务预测和 ROI 分析"
