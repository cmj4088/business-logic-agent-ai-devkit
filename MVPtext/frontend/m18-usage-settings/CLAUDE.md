## 职责范围

M18 负责用量统计和全局设置页面：
1. **用量概览**：Token 消耗总量、成本总计、按模型分布
2. **项目用量**：每个项目的 Token 消耗和成本
3. **每日趋势**：Token 消耗的每日趋势图
4. **用量限制**：配置每日/每月 Token 上限
5. **预算预警**：项目预算使用情况和预警阈值
6. **全局设置**：语言、主题、通知偏好
7. **关于页面**：版本号、开源许可、第三方依赖
8. **数据管理**：导出数据、清除所有数据（含确认）

## 数据管理

### 导出数据
- 导出所有项目数据为 JSON 文件
- 包含：项目、产出物、审核记录、用量记录
- 通过 Electron 文件对话框选择保存路径

### 清除所有数据
- 弹出二次确认对话框
- 要求输入"DELETE"确认
- 清除所有数据库记录
- 清除后退出应用

## 技能集成

### 技能用量数据的可视化展示

M18 用量统计页面需要展示由后端 `ipd-data-analysis` Skill 生成的用量分析数据：

| 展示区域 | 数据来源 | 对应 Skill | 展示方式 |
|---------|---------|-----------|---------|
| Token 消耗趋势 | M9 后端按天/周/月统计的 Token 数据 | `ipd-data-analysis` | 折线图（Chart.js） |
| 成本分布分析 | M9 后端按模型/项目/Agent 统计的成本数据 | `ipd-data-analysis` | 饼图/环形图 + 详表 |
| 预算执行分析 | M9 后端的预算 vs 实际对比数据 | `ipd-data-analysis` | 柱状图 + 进度条 + 超支预警 |
| 模型效率分析 | M9 后端的各模型性价比数据 | `ipd-data-analysis` | 散点图/雷达图 |
| 用量预测 | 基于历史数据的趋势预测 | `ipd-data-analysis` | 虚线趋势延伸 + 预测值标注 |

### 数据刷新机制

- 用量概览数据在页面加载时从后端获取
- 支持按日期范围筛选（最近 7 天/30 天/自定义）
- 每日趋势图支持按模型分色显示
- 预算预警数据实时更新（通过 M8 notifications 通道）
- 支持导出原始数据 JSON

### 分析报告集成

在用量统计页面底部提供"生成用量分析报告"功能：
- 点击后调用后端 API，触发 `ipd-data-analysis` Skill
- Skill 生成 Markdown 格式的用量分析报告
- 报告自动保存到 M5 产出物管理系统
- 报告生成完成后通过 M8 通知前端
- 用户可在 M16 产出物页面查看完整报告

## 禁止事项

1. **禁止用量数据不区分模型**（必须按模型分开统计）
2. **禁止趋势图使用过于复杂的图表库**（MVP 简单柱状图即可）
3. **禁止清除数据无二次确认**（必须输入"DELETE"）
4. **禁止清除数据前不提示导出备份**
5. **禁止用量限制可以被前端绕过**（后端 M9 强制校验）
6. **禁止设置页面缺少返回按钮**
7. **禁止 Ollama 调用不计入用量统计**（Token 数仍记录，成本为 0）
