## 职责范围

M13 负责项目创建向导页面：
1. **快速启动表单**：5 个必填项（名称、模板、时间、团队规模、预算）
2. **行业选择**：下拉选择行业类型（消费电子/医疗器械/汽车电子/航空/软件/其他）
3. **复杂度预览**：根据用户输入实时显示推荐的复杂度级别
4. **智能默认值**：根据行业和模板自动填充推荐值
5. **合规提示**：根据行业显示对应的认证/法规提醒
6. **模板预览**：选择模板后展示该模板的阶段和活动概览

## 表单设计

### 快速启动（1 分钟，5 个必填项）
```
1. 产品名称：_______________（必填，2-50 字符）
2. 选择模板：○ 硬件IPD ○ 软件IPD ○ 医疗器械IPD ○ 自定义
3. 目标时间：预计 ____ 周完成（必填，1-52）
4. 团队规模：○ 1-5人 ○ 6-20人 ○ 20人+
5. 预算上限：$_______（必填，≥ 0）

→ 系统自动生成所有默认配置
→ 点"启动"即可开始
```

### 高级选项（可折叠）
- 行业选择（影响合规提示和复杂度判定）
- 认证数量（0/1-2/3+）
- BOM 项数估算
- 是否含硬件开发

## 复杂度自动判定预览

根据用户输入实时计算并展示：
```
推荐复杂度：标准模式
原因：团队 4-10 人，BOM 21-100 项
活动数：31 个活动
预计周期：3-6 个月
[切换为轻量模式] [切换为完整模式]
```

## 合规提示示例

```
选择"医疗器械"行业时显示：
⚠️ 医疗器械需要 NMPA/FDA 认证
   - 预计认证周期：6-18 个月
   - 建议使用"完整模式"以确保合规
   - 需要准备：ISO 13485 质量管理体系
```

## 禁止事项

1. **禁止跳过必填项校验**
2. **禁止产品名称为空或超过 50 字符**
3. **禁止预算为负数**
4. **禁止复杂度判定逻辑写在前端**（前端仅展示后端返回的推荐值）
5. **禁止创建项目时不记录复杂度级别**
6. **禁止合规提示对非医疗/汽车/航空行业造成恐慌**（措辞温和）
