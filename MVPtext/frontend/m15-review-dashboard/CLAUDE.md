## 职责范围

M15 负责审核仪表盘页面：
1. **审核列表**：所有待审核事项（按项目/类型/优先级筛选）
2. **审核详情**：查看产出物内容并进行审核
3. **投票操作**：通过/驳回/需要修改（含理由输入）
4. **单人模式标识**：自动通过的审核显示"自动通过，未经人工实质审查"
5. **批量审核**：同类型审核批量操作
6. **审核历史**：已完成的审核记录
7. **行业合规提示**：审核时显示对应行业的合规提醒
8. **审核升级**：门禁失败后的升级路径（`POST /api/reviews/{id}/escalate`）
9. **遗留问题管理**：查看和追踪遗留问题（`GET /api/reviews/issues`）

## 技能集成

### 技能生成数据的展示

M15 审核仪表盘需要展示由后端 `ipd-data-analysis` Skill 生成的审核统计数据：

| 展示区域 | 数据来源 | 对应 Skill | 展示方式 |
|---------|---------|-----------|---------|
| 审核统计图表 | M6 后端聚合的审核通过率、趋势数据 | `ipd-data-analysis` | Chart.js 图表（柱状图/折线图） |
| 遗留问题分布 | M6 后端按阶段/类型统计的遗留问题 | `ipd-data-analysis` | 饼图/环形图 + 列表 |
| 行业合规统计 | M6 后端按行业统计的合规提醒频率 | `ipd-data-analysis` | 条形图 + 文本摘要 |
| 审核效率指标 | 平均审核时长、待处理事项数量 | `ipd-data-analysis` | 数字卡片 + 趋势箭头 |

### 数据刷新机制

- 审核统计图表在页面加载时从后端获取
- 审核列表通过 WebSocket 实时更新（M8 notifications 通道）
- 用户完成投票后，统计图表自动刷新
- 支持手动刷新（刷新按钮）

## 禁止事项

1. **禁止审核列表不按优先级排序**（红色 → 黄色 → 灰色）
2. **禁止审核详情不显示 AIBadge**
3. **禁止驳回时不要求填写理由**
4. **禁止自动通过的审核不显示标识**
5. **禁止合规提醒缺失或错误**
6. **禁止审核操作无确认步骤**（驳回和需要修改必须有确认弹窗）
