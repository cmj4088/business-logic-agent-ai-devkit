## 职责范围

M12 负责应用首页 Dashboard：
1. **欢迎区域**：用户名称 + 日期 + 问候语
2. **待处理事项**：需要用户操作的审核/投票/门禁
3. **自动完成事项**：Agent 最近自动完成的工作
4. **项目列表**：用户的所有项目（含状态、进度、阶段）
5. **快速入口**：创建新项目、查看审核仪表盘
6. **通知摘要**：最近的系统通知
7. **WebSocket 连接**：接收实时状态更新

## 完成标准

- [ ] 欢迎区域正确渲染（用户名称 + 日期 + 问候语）
- [ ] 待处理事项按优先级排序（红色 > 黄色 > 其他）
- [ ] 自动完成事项列表正确渲染
- [ ] 项目列表显示正确状态和进度
- [ ] 通知摘要正确显示最近通知
- [ ] "创建新项目"按钮跳转到 M13
- [ ] WebSocket 实时更新待处理事项
- [ ] 空状态友好提示（无项目时引导创建）

---

## 禁止事项

1. **禁止 Dashboard 一次性加载所有数据**（项目列表分页，通知最近 20 条）
2. **禁止硬编码用户名称或项目数据**
3. **禁止 WebSocket 连接失败时页面崩溃**（降级为轮询）
4. **禁止待处理事项排序混乱**（红色 → 黄色 → 灰色）
5. **禁止项目列表无筛选功能**（至少支持按状态筛选）
6. **禁止快速入口按钮无键盘快捷键提示**
