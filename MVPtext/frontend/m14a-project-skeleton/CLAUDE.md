# M14a: 项目详情骨架 — CLAUDE.md

> **模块编号**：M14a
> **模块名称**：项目详情骨架（前端）
> **负责 Agent**：前端开发 D
> **开发周期**：Week 4-5
> **上游依赖**：M2（工作流引擎）、M8（实时通信）
> **下游被依赖**：M14b（项目详情联调）

> **与 M14b 的关系**：M14a 负责搭建骨架（布局、组件容器、Mock 数据、WebSocket 连接框架），M14b 在骨架基础上完成全部交互联调（AgentChat 流式输出、活动交互、RecoveryPanel 等）。M14b 在 M14a 的目录中修改已有组件文件，不创建独立目录。

---

## 职责范围

M14a 负责项目详情页的骨架结构和核心组件：
1. **项目详情页布局**：左侧时间线 + 中间主内容区 + 右侧面板
2. **阶段时间线**：6 阶段时间线组件（当前阶段高亮）
3. **活动列表**：当前阶段的活动列表（已裁剪）
4. **AgentChat 基础组件**：Agent 对话展示区（骨架）
5. **门禁状态栏**：当前阶段门禁通过状态
6. **侧边栏面板**：预算/供应链/认证/竞品小组件容器
7. **项目头部**：项目名称、状态、进度条、操作按钮

## 阶段时间线

- 6 个阶段纵向排列
- 当前阶段高亮（蓝色边框 + 填充）
- 已完成阶段：绿色 ✓
- 未来阶段：灰色
- 点击已完成阶段可查看历史

## 禁止事项

1. **禁止时间线不显示阶段完成状态**
2. **禁止活动列表显示未裁剪的完整活动**
3. **禁止页面加载时无 loading 状态**
4. **禁止侧边栏小组件数据硬编码**（使用 WebSocket 或 API 数据）
5. **禁止项目不存在时不显示 404 状态**
6. **禁止 AgentChat 组件在 M14a 阶段实现完整交互**（仅骨架，M14b 联调）
