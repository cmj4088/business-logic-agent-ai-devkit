# senior-frontend — 前端开发专家

## 概述
社区插件，提供 React/TypeScript 开发模式指导，包含组件生成、bundle分析、无障碍检查和性能优化。

## 功能
- React 18 + TypeScript 最佳实践
- 组件生成（含 Props 类型定义）
- Bundle 体积分析
- 无障碍（a11y）检查
- 性能优化建议
- Tailwind CSS 最佳实践

## 安装
```
/plugin install senior-frontend
```

## 调用方式
```
/senior-frontend [任务描述]
```

## 本项目使用示例
```
/senior-frontend 创建带loading/error/empty三态的评审列表组件
/senior-frontend 优化M12 Dashboard的渲染性能
/senior-frontend 检查组件的无障碍支持
```

## 适用场景
- 新建 React 组件
- 前端性能优化
- 无障碍检查
- Bundle 体积优化
