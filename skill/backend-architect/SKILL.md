# backend-architect — 后端架构设计

## 概述
社区插件，提供后端架构模式、API设计、数据库Schema和系统设计指导。

## 功能
- FastAPI 路由设计
- RESTful API 设计
- 数据库 Schema 设计
- SQLAlchemy 2.0 async 最佳实践
- 系统架构设计
- 性能优化建议

## 安装
```
/plugin install backend-architect
```

## 调用方式
```
/backend-architect [任务描述]
```

## 本项目使用示例
```
/backend-architect 设计M5产出物管理的API接口
/backend-architect 优化数据库查询性能，添加索引
/backend-architect 设计WebSocket实时推送架构
```

## 适用场景
- 新API设计
- 数据库Schema变更
- 系统架构评审
- 性能优化
