## 三、手动启动命令（重启服务器后用）

按顺序执行：

```bash
cd /root/bla/package/src/backend

# 1. 启动主后端
PYTHONPATH=/root/bla/package/src nohup python3 -m uvicorn m0_infrastructure.main:app \
  --host 0.0.0.0 --port 8000 > logs/backend.log 2>&1 &
sleep 3

# 2. 启动 6 个独立 Agent
nohup python3 -m standalone_agent.runner --role product_manager --port 8001 > logs/agent-pm.log 2>&1 &
nohup python3 -m standalone_agent.runner --role rd --port 8002 > logs/agent-rd.log 2>&1 &
nohup python3 -m standalone_agent.runner --role qa --port 8003 > logs/agent-qa.log 2>&1 &
nohup python3 -m standalone_agent.runner --role marketing --port 8004 > logs/agent-mkt.log 2>&1 &
nohup python3 -m standalone_agent.runner --role manufacturing --port 8005 > logs/agent-mfg.log 2>&1 &
nohup python3 -m standalone_agent.runner --role finance --port 8006 > logs/agent-fin.log 2>&1 &
sleep 2

# 3. 验证健康检查
curl http://localhost:8000/api/health
for p in 8001 8002 8003 8004 8005 8006; do
  curl -s -o /dev/null -w "Port $p: %{http_code}\n" http://localhost:$p/health
done
```

## 四、停止所有服务

```bash
# 停止全部 Agent
for p in 8001 8002 8003 8004 8005 8006; do
  pid=$(lsof -ti:$p 2>/dev/null)
```

## 六、注册远程 Agent 到主后端

注册后编排器会优先通过 HTTP 调用独立 Agent，失败则降级到本地 LLM。

```bash
# 先登录获取 token
TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@bla.com","password":"admin123"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin).get('data',{}).get('access_token',''))")

# 注册全部 6 个 Agent
for pair in "product_manager:8001" "rd:8002" "qa:8003" "marketing:8004" "manufacturing:8005" "finance:8006"; do
  role="${pair%%:*}"
  port="${pair##*:}"
  curl -s -X POST http://localhost:8000/api/agents/registry \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d "{\"role\":\"$role\",\"url\":\"http://localhost:$port\"}"
done
```

> **持久化**: 注册信息保存在 `agent_registry` 表中，重启后端后 API 仍可查到，但需要登录 token。

## 十、注意事项

1. **PYTHONPATH**: 每次启动后端都必须设置，否则报 `ModuleNotFoundError: No module named 'shared'`
2. **Ollama**: 服务器上没装 Ollama，远程 Agent 推理会失败（需要安装或配云端 LLM）
3. **端口**: 8001-8006 是 Agent 端口，防火墙需要放行才能从外网访问
4. **Token**: 1 小时过期，长期运行需要刷新 token 或改用 API Key
5. **Docker**: 项目本机用的是 Docker 部署（见 `docker-compose.yml`），但服务器上直接运行的
